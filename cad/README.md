# CAD — Shapr3D

The ten-key housing was designed separately in Shapr3D. Export and add the actual **Voyager10** CAD files here when ready:

- `voyager10.shapr` — native Shapr3D project (if available)
- `voyager10.step` — editable solid model
- `plate.stl` and `case.stl` — print-ready meshes

The source photo is in `../docs/images/prototype.jpg`.

For reference, the tested Choc V1 plate dimensions are **13.7 × 13.7 mm cutouts**, **1.3 mm thick plate**, and **5 mm between cutout edges** where the layout allows. Confirm all dimensions against the current Shapr3D model before ordering a PCB or printing a final enclosure.
